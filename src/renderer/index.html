    Getting the best take out of the PD400X

    The PD400X is an end-address dynamic in the SM7B mould: cardioid, 40 Hz – 16 kHz, 24-bit/48 kHz over USB. It rejects the room very well, but only if you work it close.

    1. Connection. USB-C straight into the PC (not a hub). Use the mic's own headphone jack for monitoring: it's zero-latency. Avoid Bluetooth headphones while recording to a track.
    2. Maono Link. Turn its EQ, compressor and limiter off so you capture a raw signal. Auddo does that processing better offline, and you can't undo DSP that's baked into the take.
    3. Windows. Sound settings → PD400X → Properties: set the format to 24-bit, 48000 Hz; turn Audio enhancements off. Set the input volume to 100 and use the mic's gain knob for level.
    4. Gain. Set Windows' mic level to 100 and Maono Link's output/limiter to neutral, then do all level setting with the mic's gain knob. Sing the loudest phrase; aim for peaks around −10 dBFS. If any digital volume sits after a hot gain knob, the mic clips while the meter still looks fine; Auddo flags that as "clipping before the app".
    5. Distance. 5–8 cm (2–3 fingers) for speech and intimate Hi-Fi; 8–15 cm for belting. Lean back on loud notes instead of riding the gain. Stay on-axis: sing into the top of the grille.
    6. Room. Soft room beats big room: curtains, bed, a duvet behind you. Kill fans and aircon for the take. Mic away from the PC.
    7. Room tone. Keep the "2 s room tone" option on and stay still. It gives the denoiser a fingerprint of your room.
    8. Takes. Everything records as 32-bit float WAV into Music\Auddo, untouched. Presets are applied on a copy, so you can re-render any time.

    Going live (Discord, OBS, calls)

    1. Discord / Zoom / games need a virtual microphone. Install the free VB-CABLE, pick CABLE Input under "Send processed voice to", press Go live, and choose CABLE Output as the input device in Discord. In Discord, turn off Krisp noise suppression, echo cancellation and automatic gain: Auddo already did that work and they will fight it.
    2. OBS: either add CABLE Output as an Audio Input Capture, or skip the cable and add an Application Audio Capture source pointed at Auddo.
    3. Latency is around 40–60 ms end to end (the AI denoiser needs about 21 ms with RNNoise, or 32 ms with GTCRN). That's fine for talking and streaming. To sing along, monitor through the PD400X headphone jack rather than "Hear myself".
    4. Recording still works while live. The take is captured raw, so you can render it with the full offline chain afterwards.
